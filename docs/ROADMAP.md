# Roadmap

## Current objective

Reposition Prototype.NEXT around production AI transformation and engineering and convert that positioning into a revenue-generating offer.

## Phase 1 — Foundation

### Business
- lock positioning;
- define ICP;
- define AI Transformation Sprint;
- define implementation offer;
- define recurring partnership model.

### Brand
- finalize messaging;
- finalize visual direction;
- remove legacy agency positioning.

### Repository
- establish documentation as source of truth;
- create `AGENTS.md`;
- align Codex and Claude Code around the same documentation.

## Phase 2 — Website

- redesign homepage;
- create AI Transformation Sprint page;
- create capabilities pages;
- create case-study system;
- improve SEO foundation;
- add qualified lead CTA;
- add analytics.

## Phase 3 — Proof

Create 2–3 strong case studies.

Priority:
1. production AI workflow;
2. complex production engineering;
3. AI engineering automation or AI product.

Build one flagship end-to-end AI workflow demonstration.

## Phase 4 — Go to market

Initial activity targets:
- contact 100 U.S. founders / CEOs / CTOs / COOs;
- conduct 20 AI workflow interviews;
- refine ICP and messaging from conversations;
- close the first $15K–$30K AI Transformation engagement.

## Phase 5 — Delivery system

Standardize:
- discovery interview;
- workflow mapping;
- opportunity scoring;
- architecture templates;
- ROI model;
- prototype process;
- evaluation;
- production roadmap;
- client handoff.

## Phase 6 — Recurring revenue

Convert successful implementations into AI Systems Partnerships.

Create repeatable:
- monitoring;
- optimization;
- model upgrade;
- evaluation;
- monthly roadmap;
- workflow expansion.

## Phase 7 — Product discovery

Document repeated customer problems.

For every engagement record:
- problem;
- company type;
- frequency;
- current cost;
- willingness to pay;
- solution pattern;
- reusable components.

Do not start a standalone product until repeated customer pull is visible.

## Near-term operating principle

For the next phase, Prototype.NEXT has one mission:

**Turn production AI expertise into a repeatable commercial system.**
