# Offers

## Offer architecture

Prototype.NEXT should use a value ladder rather than a long menu of disconnected services.

## Offer 1 — AI Transformation Sprint

**Purpose:** Find, prioritize, and validate the highest-value AI opportunity inside the client's business.

Commercial target:
**$15K–$30K**

Core outcome:
A clear, validated path from workflow problem to production implementation.

See `AI-TRANSFORMATION-SPRINT.md`.

## Offer 2 — Production AI Implementation

**Purpose:** Build the validated system.

Typical scope:
- application development;
- AI architecture;
- agents;
- RAG;
- workflow orchestration;
- integrations;
- APIs;
- backend;
- data;
- evaluation;
- observability;
- deployment;
- human-in-the-loop controls.

Indicative range:
**$25K–$100K+**

Final pricing depends on:
- scope;
- risk;
- integration complexity;
- data readiness;
- security requirements;
- production SLA;
- timeline.

## Offer 3 — AI Product Engineering

For companies adding AI to an existing or new digital product.

Possible scope:
- product discovery;
- UX;
- model selection;
- AI architecture;
- frontend;
- backend;
- APIs;
- data;
- evaluation;
- analytics;
- infrastructure.

Engagements can be fixed-scope or milestone-based.

## Offer 4 — AI Systems Partnership

Recurring engagement after launch.

Indicative range:
**$5K–$20K+ per month**

Possible responsibilities:
- model upgrades;
- prompt/system optimization;
- cost optimization;
- evaluation;
- observability;
- incident review;
- workflow expansion;
- experimentation;
- new integrations;
- reliability improvement.

## Offer 5 — Specialized Production Engineering

Used selectively when Prototype.NEXT's broader engineering experience creates an advantage.

Capabilities may include:
- web;
- mobile;
- APIs;
- backend;
- Smart TV;
- media / streaming;
- connected platforms;
- cloud systems.

This capability supports the AI positioning. It should not become the homepage's primary offer.

## Pricing principle

Do not price primarily by hours.

Price based on:
- value;
- scope;
- complexity;
- risk;
- speed;
- outcome.

Time-and-materials can still be used internally or when commercially appropriate, but it should not define the brand.
